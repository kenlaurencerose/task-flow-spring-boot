# TaskFlow 

TaskFlow ist eine Webanwendung zur Verwaltung von Aufgaben (Tasks).

Im ersten Meilenstein wurde ein Spring Boot Backend erstellt, das eine GET-Route bereitstellt, über die eine Liste von Beispiel-Tasks angezeigt wird.

## Technologien

- Java
- Spring Boot
- Thymeleaf

## Projektziel

Ziel des Projekts ist es, schrittweise eine vollständige Webanwendung zu entwickeln, bestehend aus Backend und Frontend.
